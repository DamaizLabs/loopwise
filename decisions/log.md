# Registro de decisiones

Registro de las decisiones que importan y de su porqué. Solo se añade, nunca se reescribe. La fase 2 de `/level-up` apunta aquí cada automatización que acota. También puedes añadir a mano cualquier decisión que merezca recordarse.

**Formato de cada entrada:**

```
## AAAA-MM-DD — Título corto

**Decisión:** qué se decidió.

**Por qué:** el razonamiento, las restricciones y qué te haría cambiar de idea.

**Alternativas consideradas:** qué más había sobre la mesa.

**Responsable:** quién responde de ella.
```

Sé breve. Dentro de unos meses agradecerás tener apuntado el porqué, no solo el qué.
